## 📢 1. Press Release & Plugin Announcement

**FOR IMMEDIATE RELEASE**

### mtyas Announces MidiFlux: An Open Modular Generative MIDI Rack & Harmonic Sequencer Plugin

**PARIS / ONLINE** — Audio software developer **mtyas** today announced the release of **MidiFlux**, a powerful modular MIDI transformation and generative sequencing plugin for Windows (VST3, CLAP, and Standalone).

MidiFlux transforms ordinary MIDI input into intricate musical performances. Featuring **16 specialized processing blocks**—including intelligent diatonic chord voicing, polyrhythmic Euclidean generators, micro-timing humanizers, ratcheting note bursts, and pitch mutators—MidiFlux allows producers and sound designers to construct custom generative racks with fluid drag-and-drop ordering and independent **Series / Parallel routing**.

At the core of MidiFlux is an integrated **Scale Progression Sequencer** that synchronizes with host DAW timelines. Rather than staying locked to a single static scale, producers can lay down chord and scale progression blocks from $1/4$ bar to $16$ bars that dynamically steer the entire harmonic output of upstream synthesizers.

"Modern MIDI sequencers are often rigid piano rolls or locked arpeggiators," says developer mtyas. "With MidiFlux, we wanted to give composers a living, modular rack where a single note press can unfold into strummed chords, cascade into polyrhythmic delays, and adapt to changing musical keys across an entire song structure—all with zero latency and zero audio dropouts."

Under the hood, MidiFlux is built on JUCE 8 with a real-time C++20 engine engineered for zero heap allocations in the audio thread, lock-free telemetry, and non-blocking mutex architecture.

### Availability & Pricing:
MidiFlux is available immediately for Windows 64-bit in VST3, CLAP, and Standalone formats.

### 3 Creative Recipes for Sound Designers

#### Recipe 1: Neoclassical Generative Arp & Strummed Chords
1. Insert **Chord Generator**: Set `Type` to `Diatonic Auto`, `Voicing` to `Drop-2`, `Strum` to `40ms`, `Strum Dir` to `Alternate`.
2. Insert **Arpeggiator**: Set `Pattern` to `Up/Down`, `Rate` to `1/16`, `Gate` to `85%`, `Hold` to `ON`.
3. Insert **Humanizer**: Set `Groove Feel` to `Laid-Back`, `Time Jitter` to `15ms`, `Push / Pull` to `+10ms`.
4. *Result*: Expressive, rolling piano arpeggios with organic human touch from simple sustained keys.

#### Recipe 2: Cyberpunk Euclidean Bassline & Modulated Filter
1. Insert **Euclidean Rhythm**: Set `Steps` to `16`, `Hits` to `7`, `Accent` to `60%`.
2. Insert **LFO / CC Modulator**: Set `Target CC` to `74` (Filter Cutoff), `Waveform` to `Saw Down`, `Rate` to `1/8`.
3. Insert **Delay / Echo**: Set `Time` to `1/16D`, `Feedback` to `4`, `Vel Decay` to `-20%`, `Pitch Shift` to `+12 st`.
4. *Result*: Driving polyrhythmic bass sequence with evolving rhythmic filter sweeps and shimmering octave echoes.

#### Recipe 3: Shifting Ambient Soundscape with the Scale Sequencer
1. Open the **Scale Progression Sequencer**; create 4 blocks:
   - Block 1: `C Lydian` (4 Bars)
   - Block 2: `E Minor` (4 Bars)
   - Block 3: `Ab Major` (4 Bars)
   - Block 4: `Bb Mixolydian` (4 Bars)
2. Insert **Harmonizer** (Parallel Mode): Voice 1 = `Diatonic 5th Up`, Voice 2 = `Octave Up`.
3. Insert **Mutator**: Set `Mutation Rate` to `25%`, `Max Drift` to `±2 st`, `Diatonic Only` to `ON`.
4. *Result*: An ever-evolving ambient melodic progression that traverses four distinct modes without hitting a single dissonant note.
